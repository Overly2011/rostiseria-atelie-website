# Rostiseria Ateliê Website

Crie um website profissional, extremamente realista e comercial para um restaurante fictício brasileiro chamado:

ROSTISERIA ATELIÊ

Tagline:
RÖSTI · PIZZA · GASTRONOMIA

O conceito do restaurante é uma rostiseria contemporânea inspirada na gastronomia europeia, tendo o Rösti artesanal como especialidade da casa, acompanhado por pizzas autorais, entradas, sobremesas e drinks.

A identidade visual deve seguir rigorosamente a referência fornecida no briefing:

- verde oliva / verde floresta muito escuro
- creme quente
- dourado envelhecido
- marrom madeira
- preto apenas em pequenos detalhes
- iluminação quente
- aparência artesanal e sofisticada
- referências visuais discretas à gastronomia europeia
- elementos botânicos delicados
- tipografia serifada elegante combinada com uma fonte manuscrita apenas em pequenos detalhes

NÃO criar uma aparência de restaurante genérico.
NÃO usar estética futurista.
NÃO exagerar em gradientes, glassmorphism ou animações.
NÃO fazer o site parecer um template de IA.

A sensação deve ser:

“Um restaurante pequeno, autoral e muito bem cuidado em uma cidade serrana brasileira.”
